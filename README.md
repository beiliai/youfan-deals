# 优返查券

![优返查券](logo.png)

想买什么？发来淘宝或拼多多商品链接，也可以说商品名和预算。优返帮你核对当前价格、有没有券、满多少能用和到期时间，再提供可打开的推广入口。

支持商品图片卡片、最多三页查找、详情复核与连续选购。部分分享链接可能无法识别；无法确认有券时会如实说明，不宣称全网最低价。

## 使用

将此目录作为技能安装到支持 SKILL.md 的智能体工具。需要 Python 3.10+ 和联网，不需要填写淘宝、拼多多密钥。具体运行方法见 [查询说明](setup.md)。

```sh
python cards.py "抽纸" --platform all --limit 4 --pages 2 --output outputs/优返好物.html
```

macOS/Linux 可使用 python3。粘贴链接时查询原商品，不擅自换商品。推广入口失败时禁用购买跳转，不以原链接兜底。

## 推广与隐私

购买入口是推广链接，满足购物平台规则的成交可能让优返获得佣金。此功能不代下单、不付款、不承诺用户返利；入口可用不代表佣金已到账。

查询会向优返发送本次商品关键词、筛选条件、商品编号或需解析的分享链接。不主动读取完整对话、浏览历史或本机其他文件。请勿输入手机号、地址、密码或验证码。

- [隐私说明](https://youfan.beiliai.com/deals/legal/privacy.html)
- [使用说明](https://youfan.beiliai.com/deals/legal/terms.html)
- [联系支持](https://youfan.beiliai.com/deals/legal/support.html)

公开查询受请求频率和每日运营预算限制。这不是无限制的联盟接口转售服务。源代码许可不授予优返后台的无限调用权，也不代表获得第三方购物平台的接口权限。
